## Knowledge

- Every hook input carries `session_id`, `transcript_path`, `cwd`, `permission_mode` and `hook_event_name`; a tool event adds `tool_name`, `tool_input` and `tool_use_id`.
- `SessionStart` receives `source`: `startup`, `resume`, `clear`, `compact` or `fork`; its plain-text standard output, with exit code 0, enters Claude's context.
- `PreToolUse` adds context without blocking through `{"hookSpecificOutput": {"hookEventName": "PreToolUse", "additionalContext": "…"}}`, delivered next to the tool result; without `permissionDecision`, the call follows the normal permission flow.
- A missing, empty or `*` matcher fires the hook at every occurrence of the event; a plain-letter matcher is exact, `Edit|Write` means either.
- `Stop` prevents Claude from stopping through exit code 2, or through `{"decision": "block", "reason": "…"}` at the top level.
- `additionalContext`, `systemMessage` and a hook's standard output are each capped at 10,000 characters; beyond, Claude receives a file path and a preview of the first 2,000 characters.
- Hooks in a project's `.claude/settings.json` run without any approval step; `/hooks` is a read-only browser of the configured hooks.
- Default timeout of a `command` hook: 600 seconds.
